💡 Gunakan Google Chrome atau Microsoft Edge di PC/Laptop/PID untuk mengaktifkan koneksi Bluetooth.

Hubungkan pemain

Sambungkan micro:bit via Bluetooth atau pilih keyboard untuk pengujian. Keyboard: 1 pemain bebas memakai Panah/WASD; 2 pemain: Player 1 (Panah) dan Player 2 (WASD).

Pilih game

Pilih game favoritmu dan sentuh jumlah pemain untuk langsung mulai!

Monitor masukan

RX = data mentah dari micro:bit (teks dan byte heksadesimal, ↵ = newline). TX = kode yang dikirim ke micro:bit. Baris hijau = perintah yang dibaca kernel.
